# Fonctionnalités

## Gameplay
- [x] Rivière procédurale avec sinusoïdes et passages étroits
- [x] Scrolling vertical avec vitesse variable (throttle)
- [x] Collision avec les berges (dégâts progressifs)
- [x] Gestion du carburant (game over si épuisé)
- [x] Ponts à détruire (cibles bonus, 5+ PV)
- [x] Système de combo (bonus de score croissant)
