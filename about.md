# Tidal Run — Shoot'em up fluvial

Tidal Run est un shoot'em up en scrolling vertical inspiré du classique River Raid. Pilote un bateau de combat sur une rivière générée procéduralement, tire sur les ennemis et les ponts, ramasse du carburant et des power-ups. Gère ton carburant limité : tu exploses si tu rates un ravitaillement. Plus tu progresses, plus la rivière se rétrécit et les ennemis deviennent coriaces.

## Contrôles
- **ZQSD / Flèches** : direction (Z = accélérer, S = freiner/reculer, Q/D = gauche/droite)
- **Espace** : tirer (maintien pour auto-fire)
- **Shift** : précision (mouvements plus lents)
- **P** : pause, **R** : redémarrer, **Entrée** : lancer la partie

## Fonctionnalités
- Rivière à scrolling vertical avec sinusoïdes et passages étroits
- 4 bateaux (Skiff, Hydrofoil, Tug, Cutter) avec stats différentes
- 10 tiers de difficulté croissante
- Armes multiples (canon, tir rapide, dispersion, missile)
- Power-ups (carburant, réparation, bouclier, armes)
- Ennemis variés (mines, patrouilleurs, raiders, hélicos, sous-marins, jets, canonnières)
- Ponts à détruire pour marquer des points bonus
- Combo system
- Interface responsive (canvas + UI React)
