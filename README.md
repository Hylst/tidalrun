# Tidal Run

Shoot'em up fluvial en scrolling vertical inspiré de River Raid.
Jouable sur https://games.hylst.fr/tidalrun/

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# → dist/
```

## Stack

- React 19 + TypeScript 5.9
- Tailwind CSS 4
- Vite 7 + vite-plugin-singlefile
- Canvas 2D pour le rendu du jeu
